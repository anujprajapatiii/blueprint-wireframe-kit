## States and boundaries

- **Basic Seats:** opens at the observed invitation dialog; email entry and native validity checks work, Cancel/Escape dismiss, the sidebar reopens it. Invite stops with a local boundary notice rather than sending or claiming success. Full Seats links to the separate plan experiment. Basic-versus-Full selection was not present in the source, so no invented seat picker is added.
- **Affiliate:** opens at the observed dialog; dismissal and reopening work. Program information, creator contact, terms and sign-up preserve the distinct routes but stop with a local boundary note. No third-party handoff or referral result is invented.
- **Switcher:** opens at the observed three-product menu. Each product links to its corresponding local experiment. Product descriptions retain their source wording.
- **Agents:** preserves search, source/use-case filtering, selectable template summaries, original Customer Support workflow and the contextual Architect panel. Only the Customer Support workflow is known. Selecting another card displays its captured gallery copy and explicitly states that its configuration was not inspected. Creation and assistant submission stop before an unobserved outcome. The source filter options and use-case categories were not expanded in the reference; the demonstrated Source=ElevenLabs and Support/Sales/Learning categories are local filtering adaptations over the observed cards, not claims about the original filter menu. Industry is omitted because neither options nor card-industry assignments were captured. Workflow selects the one captured workflow; Preview/View details exposes captured descriptive content rather than fabricating a running agent.
- **Quickstart:** observed JavaScript code is selectable/copyable, never run. Only JavaScript was captured, so the language selector contains only that language. Other navigation and documentation controls identify the inspection boundary. Pricing links to the model-offer experiment. Personal usage balance is abstracted.
- **Model offer:** horizontal carousel arrows/keyboard scrolling expose all five captured model cards. Add credits and Auto Top Up link to their corresponding observed experiments. Billing and unobserved Agents pricing stop with a boundary notice. The dated promotion and original prices are explicitly historical source copy. No cadence selector was captured on this page, so none is fabricated. Personal plan/balance/cancellation details are removed.

## Responsive and accessibility provisions

At narrow widths, dialogs scroll within the frame, the rail hides, the gallery/workflow/assistant stack, quickstart copy moves above code, and the pricing track remains horizontally scrollable. This reflow is a prototype adaptation; only desktop references were supplied. Shared Radix dialogs, dropdowns and Select provide keyboard/focus behavior. Native forms, labels, visible focus, aria-pressed selection, named icon actions and polite status boundaries are included. Carousel movement follows reduced-motion preference. No tuning controls are added.

## Validation

Source review confirms each actionable control has a local response or links to another captured experiment, all icon actions and fields have accessible names, and no actions invoke an external service. The shared backdrop renders one trigger at every breakpoint so dialog/menu focus returns to a visible control. Carousel arrows disable at the ends. TypeScript compilation reports no errors in the platform module; other concurrent modules were incomplete at that check. Matched-width and 320 px browser review are owned by the integration pass; no claim of actual sending, agent creation, API execution, payment or conversion is made.
