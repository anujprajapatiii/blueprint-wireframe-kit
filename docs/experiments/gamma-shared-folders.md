# Shared-folder promotion

## Scope and admission

One local experiment, `gamma-shared-folders`, studies the explicit shared-folder promotion in Gamma’s home sidebar. The NEW label, benefit copy, selective-access explanation, and Create a folder action establish a feature-adoption intervention. Naming a folder, changing permissions, and opening an invitation form are routine product controls; they remain blue supporting context.

Primary intent is engagement through collaboration feature adoption. No paid-seat expansion, meaningful first value, successful invitation, or retention effect was established. There is no separate referral classification for the ordinary invitation controls.

Manual evidence review was used. The TypeSafe skill and live documentation index were consulted, but no private observation was sent to TypeSafe; an earlier automatic approval block and lack of export consent remain applicable. No model review is claimed.

## Observed sequence

- Home shows the FOLDERS promotion. Manage access opens the explanation beside it.
- The popover says: “Share a folder with just the people you choose. They get access to every gamma inside.” It names team spaces and work not meant for the whole workspace.
- Got it dismisses the Manage access banner. The folder illustration, grouping benefit, and Create a folder action remain.
- Create a folder opens a 250-character name field. The help text says the folder stays private until shared.
- Creation opens a private empty folder. Share exposes member search, workspace No access, and the owner’s Full Access.
- Permission options are Full Access, Edit, Comment, View, and No access. None was applied in the source.
- A separate rail entry exposes email/link workspace invitations. These are linked product context, not an additional growth pattern.

Learn more’s destination, actual invitation completion, permission update results, and collaboration were not inspected.

## Local behavior and limits

The prototype supports benefit-popover dismissal, local folder naming/creation, empty folder, sharing dialog, permission choices, invitation tabs, example copying, and cancellation. Generic names and `example.com` links replace private identity and access URLs. Email submission returns explicit local-only feedback and sends nothing. Permission changes update only example state and report that no real workspace access changed. Uninspected destinations end at an honest boundary.

Shared primitives provide dialogs, popovers, selection, tabs, inputs, badges, and buttons. Dialog closure restores focus to its initiating control; after creating the folder, focus falls back to Share. The dismissed promotion returns focus to Create a folder. Library Restart remounts the experiment to clear all local state.

At narrow widths, the icon rail is omitted, navigation becomes an expandable group, the sidebar promotion appears above the main content, and sharing controls wrap. These are local accessibility adaptations, not observed Gamma mobile behavior. Transitions are instant; source timing was not measured.

Guide me has two short, state-aware lessons on the promotion and its explanation. There are no extra growth tooltips or alternate teaching controls.
