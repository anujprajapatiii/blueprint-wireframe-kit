## Observed structure and behavior

On reaching home after setup, an automatic release announcement displayed “GAMMA 5”, “Our biggest update ever” and “We rebuilt how Gamma thinks, designs, and edits. Your best ideas deserve better.” The main action was “See what’s new”; the footer reassured users that “You can still use Gamma Classic.”

The action opened a five-slide tour in the same modal. In order, the slides were “More visual variety”, “Our most powerful agent”, “Import that works”, “Connect your tools” and “And so much more”. The first four described visual inspiration, one agent for several tasks, reusable PDF/PPT imports and connections to other tools. The final slide collected additional new and free capabilities.

Next and Back moved between slides, with no Back on the first slide. Five progress dots and Close were visible. A direct jump from a dot was not established during source inspection, so the presence of the dots does not by itself prove source navigation behavior. The final “Start creating” action dismissed the tour to home. A separate welcome coach then appeared and was skipped. No creation or credit use followed. A source path for reopening this announcement was not inspected.

## Admission and classification

Manual source-based admission: this is an explicit release proposition followed by specific feature benefits and a creation invitation. The primary category is provisionally **engagement and feature adoption**. Although inspected in a new account, the release message does not demonstrate first meaningful value, so activation is not asserted. Completion and feature use are separate outcomes.

The automated curator request was blocked before any model assessment. There is no model endorsement. Full classification, proposed measures and evidence limits live in the typed metadata.

## Prototype decisions and limits

Yellow covers the entire announcement and tour modal, including illustrations, navigation, close control and footer. Blue remains outside it. Decorative source artwork and branding are replaced by plain placeholders; the useful copy and sequence remain.

Library Restart is a local review provision, not an observed Gamma reopening action. The separate welcome coach is preserved as source context, not added as a second growth experiment. Routine account setup questions also remain research context rather than growth entries.

Source animation timing was not measured. Any local transition must preserve the stationary modal and its controls, support reduced motion, and avoid inventing an endless loop or nonexistent neighboring slide. Narrow-screen reflow is a prototype adaptation because mobile Gamma was not inspected. The wireframe does not generate content, connect tools or spend credits.
